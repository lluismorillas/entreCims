# entreCims

Registre local i de codi obert d'excursions. Importa tracks GPX, FIT i TCX i fotos, i consulta'ls en un mapa 2D amb el perfil d'elevació.

> **Estat:** en desenvolupament. Encara no hi ha codi que es pugui executar.

## Funcions previstes

- Registre d'excursions amb mapa, perfil d'elevació i fotos.
- Detecció automàtica dels cims assolits.
- Predicció del temps d'una ruta segons el teu ritme real.

Les teves dades es queden a la teva màquina. L'aplicació és per a un sol usuari i no té comptes.
