# Com contribuir

1. Obre una incidència per explicar el problema o la proposta.
2. Crea una branca des de `main`.
3. Fes el canvi amb les proves corresponents.
4. Obre una pull request que enllaci la incidència.

La integració contínua ha de passar abans de fusionar la pull request.

No afegeixis mai tracks ni fotos reals al repositori. Per a les proves, fes servir dades sintètiques a `sample-data/`.

Les ordres per instal·lar i executar el projecte s'afegiran quan hi hagi codi.
