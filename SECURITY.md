# Seguretat

## Arquitectura i Desplegament
Fita està dissenyada per executar-se exclusivament de manera local al teu equip. Per aquest motiu **no inclou cap sistema d'autenticació ni control d'accés**. 

## Informament de Vulnerabilitats
Si trobes cap vulnerabilitat o problema de seguretat, et demanem que **no obris una incidència pública** (Issue) a GitHub. 

En el seu lloc, utilitza la funció d'**informe privat de vulnerabilitats** de GitHub disponible al repositori per notificar-ho de manera segura. Així ens donaràs un marge de temps adequat per solucionar-ho abans que sigui públic.
